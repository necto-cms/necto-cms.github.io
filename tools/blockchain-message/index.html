Message Chain

AES-256 encrypted · SHA256 integrity · per-message keys

Write a sequence of encrypted messages where each one is cryptographically linked to the one before it. Share the chain file — the recipient can only read messages in order, and any tampering is instantly detected.

Practical uses

  • Sequential secret handover — Leave a chain of instructions where each step is revealed only after the previous one is read — perfect for inheritance or offboarding
  • Tamper-proof evidence log — Record findings in a cryptographically linked chain — any retroactive edit is immediately detectable via chain verification
  • Encrypted story / campaign — Write a multi-chapter narrative where each chapter is encrypted and unlocked in sequence; export and share the chain file
  • Progressive disclosure — Stage sensitive information so it can only be consumed in order — each message builds on the last, with independent encryption per block
